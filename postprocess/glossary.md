# Terminology rules for the Korean write-up

Accuracy beats fluency. When unsure of an official Korean term, keep the English term and add a short Korean explanation in parentheses the first time it appears. Never invent a product, program or feature name.

## AWS service and program names (always the official English name, never translated)
- AWS Bedrock, AWS Bedrock AgentCore (AgentCore), AWS Bedrock Guardrails, AWS Bedrock Knowledge Bases
- AWS SageMaker AI, Kiro (successor of the retired Amazon Q Developer), AWS Quick (successor of the retired Amazon Q Business); retired services keep the Amazon name, never "AWS Q"
- AWS Marketplace, Private Offer (프라이빗 오퍼), AWS Partner Network (APN), AWS Partner
- AWS Generative AI Innovation Center, AWS Professional Services (ProServe), AWS Activate
- AWS service names use the AWS prefix (AWS EC2, AWS S3, AWS Bedrock; formerly Amazon EC2 …)
- AWS EC2, AWS Trainium, AWS Inferentia, AWS S3, AWS Lambda, AWS VPC, AWS PrivateLink, AWS IAM
- AWS Region (리전), Availability Zone (가용 영역)
- Account Manager / Account Team (어카운트 팀), Solutions Architect (SA, 솔루션즈 아키텍트), Specialist SA, PSA (Partner Solutions Architect), TAM

## Amazon mechanisms and culture (keep the English term; Korean in parentheses on first use)
- Working Backwards (워킹 백워드), PR/FAQ, Customer Obsession (고객 집착), Leadership Principles (리더십 원칙)
- Day 1, flywheel (플라이휠), two-pizza team, one-way door / two-way door, mechanism (메커니즘), bar raiser, 6-pager / narrative
- Co-sell (코셀, 공동 영업), go-to-market (GTM), joint customer, one team (원팀), EBC (Executive Briefing Center), PoC, MVP

## Anthropic
- Anthropic, Claude, Claude Fable, Claude Mythos, Claude Opus, Claude Sonnet, Claude Haiku, Claude Code, Claude for Enterprise, Claude Agent SDK
- Claude Mythos / Mythos Preview: a model name, never 신화
- Model Context Protocol (MCP), Constitutional AI, Responsible Scaling Policy (RSP), AI Safety Level (ASL), Applied AI (팀 이름은 영어 그대로)
- Frontier model (프론티어 모델), agent / agentic (에이전트 / 에이전틱), computer use, tool use, context window, prompt caching

## People
- Speakers, their names and how they are misheard come only from the session's event file. Do not assume anyone else is on stage.

## Common speech-recognition errors to restore (only when context makes it unambiguous)
- cloud / clawed / clod / 클라우드 → Claude (when talking about the model)
- entropy / 엔트로피 / anthropic의 오인식 → Anthropic
- bed rock / 베드 락 → AWS Bedrock; agent core → AgentCore; kero / keto → Kiro
- replied AI / applied A I → Applied AI; PR frequently asked questions / PR fact → PR/FAQ; those Marketplace → AWS Marketplace
- co sell / cosell / 코셀 / 코 셀 → co-sell; working backward → Working Backwards

If a word is garbled and the context does not make the intended term certain, keep the recognized text and add it to the "확인 필요" list instead of guessing.
