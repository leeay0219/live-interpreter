This is a prepared talk on a big screen for a large audience.
- The slide text in the context is authoritative: when the speaker says a product, program or number from the slide, write it exactly as on the slide.
- The speaker is presenting, so finished sentences use polished but still spoken 합니다 style; questions to the audience stay questions.
- Applause lines, jokes and greetings are short; translate them briefly instead of skipping them.
